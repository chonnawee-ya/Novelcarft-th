# คู่มือการใช้งาน PlotCraft TH (User Guide)

คู่มือสำหรับนักเขียนตั้งแต่การตั้งค่า AI ครั้งแรก ไปจนถึงการแต่งนิยายและส่งออกต้นฉบับพร้อมลง ReadAWrite / Dek-D / Obsidian

---

## 1. การตั้งค่า AI Provider ครั้งแรก

1. คลิกปุ่ม **ตั้งค่า AI API** ที่มุมขวาบน
2. เลือกผู้ให้บริการที่ต้องการ:
   - **OpenRouter (แนะนำ):** ใช้คีย์เดียวเลือกได้ทุกค่าย (Gemini, Claude, GPT, DeepSeek, Llama) ไม่ติด CORS
   - **Google Gemini:** ใส่คีย์จาก Google AI Studio แล้วกด **"ดึงรายชื่อโมเดลที่ใช้ได้จริง"** เพื่อเลือกรุ่นล่าสุด
   - **OpenAI / Anthropic Claude / DeepSeek / Groq / Typhoon:** ใส่คีย์ของแต่ละค่ายได้โดยตรง (ระบบแยกเก็บคีย์ให้แต่ละค่าย สลับไปมาได้)
   - **Ollama / LM Studio (Local):** รันฟรีบนเครื่องตัวเอง ไม่ต้องใส่ API Key
   - **Custom OpenAI API:** กรอก Base URL + API Key และติ๊ก **"เปิดใช้ Local CORS Proxy"** หากเซิร์ฟเวอร์ปลายทางไม่เปิด CORS
3. *(แนะนำเพื่อประหยัดค่า API)* กรอก **Fast Model** (เช่น `gpt-4o-mini` หรือ `deepseek-chat`) เพื่อใช้กับงานเบา
4. กด **ทดสอบการเชื่อมต่อ (Test Connection)** → หากขึ้นสีเขียว ให้กด **บันทึกการตั้งค่า**

---

## 2. วิธีสร้างนิยายเรื่องใหม่ (3 โหมด)

กดปุ่ม **+ สร้างโครงเรื่องใหม่** บนหน้า Dashboard แล้วเลือกโหมดที่ถนัด:

### โหมดที่ 1: แต่งสำเร็จรูป (Auto-Pilot) — *ง่ายและเร็วที่สุด*
1. พิมพ์ไอเดียสั้นๆ 1–3 ประโยค (หรือกด **สุ่มไอเดียตั้งต้น**)
2. คลิกเลือก **Trope Boosters** ที่อยากผสมเข้าไป (ไม่บังคับ เช่น *พระเอกคลั่งรัก, หักมุมตอนจบ*)
3. กด **"ให้ AI วิเคราะห์และเลือกทุกอย่างให้"**
4. ตรวจสอบ **พิมพ์เขียวที่ AI เลือกให้** (เลือกชื่อเรื่องจาก 3 ตัวเลือก และปรับแก้จำนวนตอน/POV ได้ตามใจ)
5. กด **"Full Auto-Pilot: สร้างโครง + ตอนที่ 1–5 + แต่งตอนที่ 1 ทันที!"** เพื่อรับโครงเรื่องพร้อมเนื้อหาตอนที่ 1 ที่อ่านได้ทันที

### โหมดที่ 2: ตั้งค่าเองแบบละเอียด (Custom)
- เลือกแนวนิยาย (ผสมได้สูงสุด 3 แนว), เลือก 1 ใน 7 ทฤษฎีโครงสร้าง (กดลูกศรดูจังหวะย่อยของแต่ละทฤษฎีได้), โทนเรื่อง, กลุ่มเป้าหมาย และจำนวนตอนเป้าหมายเองทั้งหมด

### โหมดที่ 3: นำเข้าโน้ตเดิม (Import Draft)
- วางโน้ตไอเดียเดิม หรือกด **อัปโหลด `.txt` / `.md`** เพื่อให้ AI สกัดตัวละคร โลก และโครงเรื่องลงระบบโดยยึดแก่นเรื่องเดิมของคุณ

---

## 3. การทำงานใน Workspace ทั้ง 5 แท็บ

1. **ภาพรวม & โครงเรื่องหลัก:**
   - คลิกแก้ Logline, Rolling Summary หรือ Plot Beats ได้ทุกช่อง
   - หาก Rolling Summary เริ่มยาว กดปุ่ม **บีบอัดสรุป (ประหยัด Token)** ได้ใน 1 คลิก
   - กด **เจนใหม่** รายจังหวะพร้อมพิมพ์ **Steering Prompt** บอกทิศทางที่ต้องการได้
2. **โลกและกฎเกณฑ์ (Lore Bible):**
   - การ์ดที่กด **ปักหมุด (📌)** จะถูกส่งให้ AI ยึดเป็นกฎเหล็กเสมอ (แนะนำปักหมุดเฉพาะกฎสำคัญรวมกับตัวละครไม่เกิน 10 การ์ดเพื่อประหยัด Token)
3. **ตัวละคร (Characters):**
   - แก้ไขเป้าหมาย ปมในใจ ภูมิหลัง ความสัมพันธ์ ปักหมุดตัวละครสำคัญ หรือกด **ให้ AI เจนตัวละครเพิ่ม**
4. **โครงสร้างรายตอน (Chapter Beats):**
   - กด **+ สร้าง 5 ตอนถัดไป** (หรือ 3 ตอนในโหมดประหยัด) เพื่อขยายโครงเรื่องไปเรื่อยๆ จนครบจำนวนตอนเป้าหมาย
   - เลื่อนลำดับตอนขึ้น/ลงได้ (ระบบรันเลขตอนใหม่อัตโนมัติ) หรือกด **เจนใหม่** เฉพาะตอนที่ต้องการแก้
5. **แต่งนิยายเต็มตอน (Stage 3 Writer Studio):**
   - **ลองชิม 3 สำนวน (Style Anchor):** กดก่อนเริ่มแต่ง เพื่อเลือกสำนวนภาษาที่ชอบคุมโทนทั้งเล่ม
   - **แต่งตอนนี้ให้เสร็จด้วย AI:** เขียนเนื้อหาเต็มตอนโดยต่อฉากจากตอนก่อนหน้าอัตโนมัติ
   - **Auto-Pilot แต่งตอนที่เหลือทั้งหมด:** สั่งแต่งต่อเนื่องทีละตอนอัตโนมัติ (กดยกเลิกได้ทุกเมื่อ)
   - **Highlight-to-Refine (แก้เฉพาะย่อหน้า):** ลากคลุมเฉพาะข้อความที่อยากแก้ในช่องเนื้อเรื่อง → แถบสีเขียวจะโผล่ขึ้นมา กด **ปรับเฉพาะท่อนที่เลือก** เพื่อประหยัด Token 80–90%

---

## 4. เครื่องมือตรวจสอบ สำรองข้อมูล และส่งออก

- **ตรวจพล็อตโฮล (AI Audit):** กดปุ่ม **ตรวจพล็อตโฮล** ด้านบนของ Workspace เพื่อดูคะแนนความสมเหตุสมผล (0–100) และรายการจุดขัดแย้งพร้อมวิธีแก้
- **Undo:** ทุกครั้งที่สั่ง AI เจนใหม่หรือลบการ์ด สามารถกด **Undo** ด้านบนเพื่อย้อนกลับได้สูงสุด 20 ขั้น
- **โหมดประหยัด (`⚡`):** กดเปิด-ปิดได้ทันทีจากแถบด้านบนของ Workspace คู่กับตัวเลขประมาณการ Token (`~X tok`)
- **Export:**
  - **ต้นฉบับนิยาย (`.md` / `.txt`):** เฉพาะเนื้อหาตอนที่แต่งแล้ว พร้อมก๊อปปี้ลง ReadAWrite / Dek-D
  - **โครงเรื่องทั้งหมด (`.md` / `.txt` / `.json`):** สำหรับเก็บใน Obsidian / Notion หรือสำรองโปรเจกต์ย้ายเครื่อง (นำกลับเข้ามาได้ด้วยปุ่ม **Import Backup** บนหน้า Dashboard)
